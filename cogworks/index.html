Metagraph workbench

One typed metagraph, many projections. Layers composite like GIS; modes re-project the same model.

Interaction

  • Scroll — zoom · drag background — pan · drag node — move & pin · double-click node — unpin
  • Click — select node / hull · Esc — clear selection · F — fit view · ? — this card
  • Search matches names and tag values; Enter zooms to matches.
  • Selecting a tenant (tree or hull) reveals its hull even when the tenancy layer is off.

Model schema (native)

{
  "nodes":      [{ "id", "type", "name", "ns", "tags": { … } }],
  "edges":      [{ "source", "target", "type", "tags": { "protocol", "rate", … } }],
  "hyperedges": [{ "id", "type", "name", "members": [nodeId, …], "tags": { … } }]
}
node types: hw · net · cluster · workload · pkg · storage · ns · tenant(hyper-only)
edge types: link · tunnel · flow · dep · nfs · sched · nsrel
hyper types: dep (closure) · tenancy · mesh
d9 dialect: { "Pkgs": [{FamNam,Version}], "Wlds": [{Id, Pkgs:[…]}] } is auto-detected.

API

Workbench.load(model) · Workbench.importD9(json) · Workbench.model
